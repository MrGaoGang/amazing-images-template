# 模板 4：第二世界摄影二创海报

## 输入

- 一张用户上传的摄影原图；原图是主体、色彩、光线与空间关系的唯一依据。
- 默认输出为 3:4 竖版海报。用户明确提出的其他尺寸或文字要求优先。
- 当前暂无本模板案例图。其他模板案例不能代替原照，也不能作为本模板的固定构图参考。

## 默认构图

- 画面严格上下 1:1 分区：上半与下半等高，水平衔接；成品整体为 3:4 竖版。
- 上半尽可能忠实保留原照片，只做必要的等比裁切。不得改变主体、人物动作、空间关系、色彩、自然光影或重新设计摄影内容。
- 下半使用自然、温暖的米白色纸张背景，保留大量干净留白。
- 不套用固定的撕纸边、小人站立或指定文字角落。摄影剪贴的轮廓、切口或延伸方式，应从照片中辨识度最高的结构自然产生，并参与解释画面。

## 执行提示词

请基于我上传的摄影作品，制作一张 3:4 竖版的「第二世界」摄影二创海报。

整体严格上下 1:1：
上半部分尽可能忠实保留原照片，不改变主体、人物动作、空间关系、色彩和自然光影，只做必要的等比裁切。
下半部分使用自然暖米色纸张背景，保留大量留白。
但不要直接套用“撕纸+小人”的固定模板。

生成之前，请先认真观察这张照片：
1. 找出照片里最有辨识度的视觉结构，而不只是识别题材。例如水波、道路、倒影、云层、枝条、光束、影子、建筑边缘、人物动作、山脊等。
2. 问自己：“如果照片里的这个结构真的变成一种可以被触碰、使用或改变的东西，它最自然会是什么？”由此找到只属于这张照片的“第二世界”。可能发生的变化包括但不限于拉、推、拨开、进入、打捞、测量、修补、展开、铺平、攀爬、连接、收集；不要机械复用这些动作。
3. 摄影剪贴的形状本身也必须参与解释照片。不要默认使用普通不规则撕纸边。水可以成为一块小水域，光可以成为某种可被借用的东西，道路可以继续延伸，云或树枝也可能形成新的空间关系。具体答案必须从这一张照片本身产生。
4. 可以加入 0–3 个极简黑色手绘线稿人物。小人不是装饰，而是这个第二世界里的“使用者”。他们必须真正与照片中的物理结构互动，而不是站在旁边摆姿势。如果原照片已经有很强的人物动作，可以不新增小人。
5. 根据这张照片具体发生的事情，生成一句简短英文手写旁白。语气自然、轻松，有一点幽默或画外音感。不要写成励志语录，也不要重复“Same..., different...”这类固定句式。文字位置根据画面留白和动作方向决定，不固定在某个角落。

整体风格：
真实摄影 + 米白纸张 + 极简黑线涂鸦；干净、明亮、克制，有轻微手工拼贴感和独立杂志感。

不要：
商业广告感、复杂插画、密集小人、固定撕纸模板、重复动作、为了好看随意添加树叶星星等装饰、擅自改变原照片色彩或重新设计摄影内容。

最重要的原则：不要装饰照片。先理解照片，再发现它里面原本就可能存在的另一个世界。理想结果应该让人看到后觉得：“原来这张照片本来就可以这样理解。”

## 避免项

- 不把某种题材、互动动作、剪贴外形、人物数量或文字位置写成固定答案；每次都根据当前照片判断。
- 不为填充留白添加无关道具、装饰图案、额外摄影内容或复杂场景。
- 不让小人仅作摆姿势或装饰；若找不到自然可信的结构互动，就不加小人。
- 不生成多句说明、口号或励志文案；默认只保留一句英文手写旁白。

## 验收条件

- 画布为 3:4 竖版，上下区域等高。
- 上半主体、动作、空间关系、色彩与自然光影仍与原图一致，仅有必要的比例裁切。
- 下半为自然暖米色纸面并留白充足。
- 第二世界来自照片中特有的视觉结构；剪贴形状与互动方式共同表达这一解释，没有机械套用固定模板。
- 黑色线稿人物为 0–3 个且确实与结构互动；原图已有强人物动作时允许不增加人物。
- 英文旁白简短、轻松、有画外音感，并放在适合画面留白与动作方向的位置。
- 无广告感、无随意装饰、无对摄影内容的擅自改色或重构。
